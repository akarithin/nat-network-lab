SNAT

Static (one-to-one), Dynamic IP (many-to-many), and DIPP (many-to-one using ports).

DNAT

Port translation

Port forwarding maps a public IP and port to an internal IP and port.

Static NAT

Dynamic NAT

Allocates public IPs from a predefined pool. Typically, each active translation needs a public IP.

Many private hosts share one or more public IPs. Source port numbers distinguish connections.

Dynamic NAT is different: its translation is created dynamically and may expire when the session ends, so the public IP is not a reliable inbound destination for the original host.

Destination NAT (DNAT)

Internet → Private network

Static DNAT (1:1)

Maps one public IP address to one internal private IP address. Common examples include web, mail and application servers.

Example
13.1.1.10 → 172.16.1.10

Static PAT / Port forwarding

Maps a public IP and port to an internal IP and port. The external and internal port numbers can differ.

Example
13.1.1.10:443 → 172.16.1.10:22

Dynamic DNAT

Translates the original destination address to a destination host that may have a DHCP-assigned IP. The lesson notes FQDN, address object or address group as possible translated-address references.

Real-world practice scenarios

Think like a network engineer
SCENARIO 01

500 users, one public IP

Problem: A company has 500 users but only one public IP for internet access.

Solution: Use DIPP NAT so multiple private IPs share a public IP using different source ports.

SCENARIO 02

Publish a web server

Problem: An internal web server must be reachable from the internet.

Solution: Use Static NAT with a public IP and allow the required HTTP/HTTPS traffic in the security policy.

SCENARIO 03

VoIP port changes

Problem: SIP calls drop because source ports change.

Solution: The notes recommend Dynamic IP (without port translation) to retain original ports.

Quick design question

A company wants users to browse the internet through one public IP. Which NAT method best matches the requirement?

DIPP / PAT. It translates multiple private IP addresses to one or more public IPs and uses source ports to distinguish connections.
